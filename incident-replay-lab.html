Interactive cybersecurity project · Event analysis

Incident Replay Lab

A browser-based learning project that replays synthetic Windows Security and pfSense firewall events, applies clear detection rules and turns related activity into incidents that can be reviewed step by step. It is a simulation for explaining event analysis—not a live monitoring service or production security platform.

01 Approach

Make every detection understandable from event to incident.

I wanted to explore how technical events become actionable security information without hiding the reasoning behind a complex model. Each scenario has a known sequence, an explicit threshold and a visible score breakdown, so a visitor can inspect why an incident appeared.

01 / NORMALISE

One event structure

Windows and firewall fixtures are validated and converted into a consistent event shape before analysis.

02 / DETECT

Transparent rules

Deterministic rules count related events, check the documented threshold and return an explainable match.

03 / INVESTIGATE

Connected evidence

The incident view keeps the severity, matched rule, supporting events, notes, status and audit history together.

02 Scenarios

Four small simulations cover authentication and firewall activity.

Why deterministic rules?

They suit the scale and purpose of this project: the visitor can trace the input, threshold and outcome directly. The project does not use AI, claim predictive ability or imply that four rules are sufficient for a real organisation.

05 Limitations

A focused technical demonstration with deliberately clear boundaries.

  • 01
    Every event and identity is fictional and intentionally created for the four documented scenarios.
  • 02
    The application does not connect to live Windows hosts, firewalls, accounts or organisational data.
  • 03
    Incident changes are stored only in the visitor's browser; there is no backend, shared database or user authentication.
  • 04
    The rules demonstrate detection concepts but have not been tuned or validated for real operational environments.
  • 05
    The project is a learning simulation, not a SOC product, managed security service or production-ready platform.
