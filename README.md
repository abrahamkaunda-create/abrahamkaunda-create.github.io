## Projects

### Personal portfolio website

A responsive static website featuring accessible navigation, light and dark themes, and automated deployment through GitHub Pages.

A documented final-year university project exploring network security using pfSense in a virtualised environment, including firewall rules, network segmentation, VPN technologies and performance trade-offs.

## Running locally

No installation is required. Download or clone the repository and open `index.html` in a browser.

Alternatively, run a local server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.
